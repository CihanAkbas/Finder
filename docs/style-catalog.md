# GTA VI style catalog

`/gta6/style` offers public reference looks, item ownership, saved looks, private outfit building, acquisition filters, source inventories, and map links. Wardrobe fields use the existing per-account Firebase synchronization and offline storage. They do not change map completion. The large style catalog is loaded through a separate dynamic module.

Snapshot reviewed 2026-11-27: **5,390 items, 489 public looks, 229 stores, and 4 magazine sources**. All records returned by the guest catalog at that time are included. These are source snapshot counts, not a claim about future additions or all game content. Two items have no source image. Seventy-six public looks have no shared piece list; the UI states this instead of displaying 0/0 as progress.

The original short import was incomplete because it used old HTML index caches. The original API 403 was caused by a missing public `X-Client: web` protocol header. The guest site uses this header without authentication. The importer now reads the public `/api/units` and paginated `/api/comps` JSON responses with `Accept: application/json` and this client header. It sends no cookies, bearer tokens or private account data. It does not impersonate a browser, solve a challenge, rotate addresses or retry rejected requests. An HTTP error aborts before replacing the catalog. Pagination must reach the advertised count; repeated or incomplete pages abort. Cached responses make interrupted runs resumable.

Run `STYLE_FETCH_PUBLIC=1 node --import tsx scripts/import-style-catalog.mts` (set the environment variable using your shell's syntax). By default, existing public JSON snapshots in the OS temporary directory are reused. Set `STYLE_REFRESH_INDEX=1` with `STYLE_FETCH_PUBLIC=1` to refresh them. Requests are sequential and spaced by at least 1.1 seconds. Inspect the diff and run the catalog integrity tests before committing. Retired items and looks are retained as archived records so previous saved IDs survive.

Only factual item metadata, public creator usernames, image URLs and source links are stored. API fields such as user IDs, IP fields, votes and descriptions are discarded. Public creator names remain on looks. Source URLs remain in catalog metadata for maintenance; promotional source text and external source links are omitted from the player interface. In-game names remain original; category labels and acquisition notes have Turkish and English UI text. Acquisition notes explain wardrobe rewards, collectible rewards, magazine scans, salon/tattoo menus and components bought with ready-made outfits. Unpublished prices and specific unlock conditions are not invented.

Thumbnails use the standard Next.js image optimizer, with narrowly allowed HTTPS paths on `cdn.gtafits.com`, no redirects, and no forwarded credentials. The optimizer fetches ordinary public images, resizes and caches them. This fixes the browser's direct-image loading failures. Missing images retain a source-link fallback.

Map links reuse **198 existing canonical pins**; no map markers are created or moved. Matching requires both a place name and source-coordinate agreement. Two map projections are calibrated using 138 uniquely named reference locations, with robust medians and a maximum accepted 95th-percentile error of 0.0005. The snapshot's 95th-percentile residual is about 0.000209. Ambiguous or distant candidates are rejected. The remaining 31 stores link to their source position on the existing map. Four magazine sources do not publish coordinates. Calibration evidence and source coordinates are included in the snapshot for review.

Style filters use the shared searchable HudSelect with explicit dark listbox and option colors, avoiding native Windows popup theme mismatches.

The player style page opens directly on Pieces. The promotional summary and community Looks gallery are omitted; personal outfit building remains available under My outfits. Catalog look records and previously saved IDs remain in storage for compatibility.

Coverage rechecked against the public guest catalog on 2026-11-27: 5,390 source items, 5,390 local items, zero missing source slugs, two source items without an image. This verifies source-catalog parity; an official complete in-game wardrobe inventory is not available to establish whole-game completeness.
